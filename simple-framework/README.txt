SIMPLE FRAMEWORK - ONE-TIME SETUP

1. Subscribe to Simple Framework and the mods you want.
2. Let Steam finish downloading.
3. Close Subsistence.
4. Download and open Simple Framework Setup. Follow the setup window.
5. Open Steam and start Subsistence.
6. Enable Simple Framework and your chosen mods, then play.

You only run Setup once. After that, let Steam finish normal updates and
play as usual. Compatible updates and ordinary cache recovery use the same
connection automatically. You do not need to copy a launch line.

Keep your existing worlds and saves. If Kevin already works, your current
connection stays available until you choose the one-time Framework transition.
Kevin is optional for Simple Sorting and Simple Raid Alerts through Framework.

Workshop page and Setup download:
https://steamcommunity.com/sharedfiles/filedetails/?id=3824274376

If something needs attention, keep the message when asking for help.
Keep your saves and working files.

For Windows Subsistence Alpha 68.19, single-player.
Multiplayer and dedicated-server support are future work.

FOR CREATORS
Participating mods use a signed, versioned manifest and a native lifecycle module.
Steam delivers their content; Framework checks ownership, dependencies and package
identities before mounting a complete compatible set outside the game's core files.
The current loader supports compiled UnrealScript .u packages. Standalone .upk
assets and maps, breaking state migrations and server versions are future work.

Creator guide:
https://github.com/SimpleNeb/Subsistence-Kevin/blob/main/simple-framework/CREATOR-GUIDE.txt

The kit includes the manifest contract, an example module and local signing-tool
source. Authors supply their own compatible UnrealScript build environment.

FREE, AND BUILT FOR THE COMMUNITY
Simple Framework exists to give the Subsistence modding community a foundation
to build on. I want more people to be able to create, share and make this game
their own. I do not want access to that opportunity to depend on permission from me.

My work on Simple Framework and these mods will remain free. I will not monetize
it or accept donations. I do this because I love creating and sharing it.

access to these mods free as well.
